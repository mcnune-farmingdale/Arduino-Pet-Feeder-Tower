# Arduino-Pet-Feeder-Tower

## Description
  This Feeder Tower is a simple design that dispenses pet food with a motor equipped with rubber blades to push the dry food into the dispenser. The food is held in by a servo that controls the door to the dispenser. The tank can hold up to 8L of dry food (approximately 33 cups) and is resupplied from the top of the tower. The LCD on the front of the building will display the current time and selected portion amount, as well as a menu operated with the IR remote. The food tank will also contain a force sensor that can send information to other robots if the tank is getting low on food. 

## Expected Function
  Once the robot begins running, it will await a command from the IR remote. Pressing the Function button will open a menu screen with options for portion size, scheduling meals, and setting the clock. The portion size will have three options determining how long the motor spins (and, in turn, how much food is dispensed). Setting the clock is optional but allows the robot to operate independently if meals are set up. Up to three meals can be set up, each assigned to an hour and minute combination. If the Play/Pause button is pressed, the robot will dispense an amount of food equal to the current portion size. Once the on/off button is pressed, the device will enter a low power mode and only check in periodically to see if it is meal time.
